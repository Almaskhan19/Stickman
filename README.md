# Stickman Bridge

Stickman Bridge is a lightweight HTML5 arcade game where the player must stretch a bridge to cross between pillars. The goal is to survive as long as possible, collect coins, and achieve the highest score.

The game is built using **HTML5 Canvas, JavaScript, and CSS** and demonstrates core browser-game concepts such as animation loops, procedural generation, collision detection, and persistent player data.

## Features
- Smooth canvas-based gameplay
- Animated stickman character
- Procedurally generated bridges
- Coin collection system
- Player profiles
- Local leaderboard
- Parallax background
- Installable PWA support
